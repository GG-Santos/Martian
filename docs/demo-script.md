# Three-minute Marswalk demonstration

## 0:00–0:30 — Locate the mission
Open the app. “This is a 2.048 km patch in Jezero Crater. The map uses observations from multiple NASA missions. The habitat and three field stations are hypothetical.” Orbit the terrain and identify the habitat and return loop. Point out elevation is 1x.

## 0:30–1:15 — Read the landscape
Toggle Terrain slope and inspect the amber legend; the threshold is illustrative. Show Optical imagery as surface texture context. Toggle Thermal context and explain its ~100 m native resolution and relative IR brightness. It does not indicate current temperature. Return to the optical view so the route stays readable.

## 1:15–2:15 — Make a decision
The initial loop is about 3.06 km, 42 m ascent and 132 minutes, exceeding a 120-minute illustrative allowance. Select station B and read the relief question. Selection alone leaves the route unchanged. Exclude B and observe the shortened route and reduced dwell. Describe the tradeoff: less science coverage for a shorter excursion. Restore the preset. Open Edit route, add a waypoint near 600 E / 500 N, and observe updated distance/time. Explain that these straight segments require manual review for obstacles. Restore the preset again.

## 2:15–3:00 — Explain the evidence
Use the elevation profile slider to locate a sample on the route. Open Sources & assumptions: observations are archival; source dates are unknown where unverified. The time estimate is distance/speed plus stop dwell, not a spacesuit simulation. The rover panorama is regional context. Export JSON to preserve coordinates, source IDs, assumptions and the return leg. Finish with a useful question: which science stop would you prioritize within the available excursion time?
