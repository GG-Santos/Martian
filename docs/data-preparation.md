# Mars data preparation

## Expedition package

Three additional 512 m square HiRISE height tiles use 1 m output spacing, close to the 1.009663 m source sampling. Each is a north-first 513 × 513 little-endian Float32 array, 1,052,676 bytes. Local bounds are A (376,456)–(888,968), B (896,1096)–(1408,1608), and C (1328,648)–(1840,1160). `package_detail_tiles` uses the same sample-center transform as the overview. The renderer blends the outer 8 m into the overview and removes the replaced overview triangles. Only one detail tile is active. Optical imagery remains the original 2048² crop. Route calculations and terrain readings use the 8 m analysis grid, regardless of the displayed detail.

`scripts/prepare_expedition_evidence.py` builds `expedition-evidence.json`. To reproduce, download the CSV products listed under `weather.products` in `data/jezero/expedition-sources.json`, and their `.xml` labels, into `.data-staging/expedition/`. Download the regional `source` URL as `M20_traverse.json` into that directory. Verify each source SHA-256 against the recorded metadata before running the script. Original large downloads stay untracked.

The weather slice is MEDA sol 119, June 20–21, 2021. It includes ATS_LOCAL_TEMP1, BAROCAP1_PRESSURE and BOOM1_HORIZONTAL_WIND_SPEED from calibrated PDS products. Temperature is converted from kelvin to Celsius. Select one exact sample per channel within ten minutes of each three-hour LMST bin, with independent channel timestamps. Wind requires stable control and a motionless rover. PS/WS samples must also have a usable derived magnitude at the same spacecraft clock, following MEDA RDR SIS section 3.3.4. Empty cells and fill sentinels remain unavailable. Zero wind is retained. These are historical per-detector observations at the rover, not weather forecasts at the hypothetical stations. Product IDs, units, times, hashes and channel conventions remain in the package.

The regional inset uses NASA/JPL M20 MMGIS traverse geometry restricted to sols ≤690, with the last available drive on sol 686. Transform Mars planetocentric east longitude/latitude into the patch's PDS equirectangular frame. Simplify to 10 m point spacing while retaining leg endpoints. The playable footprint shares that frame. Three Forks links to NASA's depot record completed on sol 690; the inset does not invent a depot coordinate. This archived geometry is bundled locally and its upstream source hash is recorded.
Install `python -m pip install -r scripts/requirements.txt`. Download the HiRISE source/label URLs in `data/jezero/source-manifest.json` to `.data-staging/dtm.img`, `optical.jp2`, and `optical.lbl`. THEMIS is window-read from its public COG. Run `python scripts/prepare_mars_data.py`; then `python scripts/prepare_mars_data.py --verify-only`.

Patch: 2048 m square, centered 18.467158 N, 77.52 E. HiRISE source scale 1.009663 m; runtime analysis 8 m, optical 1 m, THEMIS native 100 m. All height values are real source-derived meters above Mars 2000 equipotential datum, not procedural terrain. Source files stay untracked.

The optical JP2 embedded CRS describes an incorrect latitude-of-origin; use identical PDS-label projection/offsets from the optical and DTM labels. Reading the JP2 as a GDAL band ignored the override and produced empty optical coverage; explicitly reading a bounded array and applying the PDS transform fixed the reproduced failure. Labels are retained in data/jezero.

THEMIS is qualitative 8-bit daytime IR brightness, not temperature. STAC acquisition dates are reversed; dates remain unknown. HiRISE source acquisition dates were not verified and are likewise shown unknown. Overview optical DN values are contrast imagery, not calibrated reflectance. The slope overlay is derived from the 8 m analysis grid; small hazards are unresolved.

Credits: NASA/JPL-Caltech/UArizona/USGS (HiRISE), NASA/USGS/ASU (THEMIS, CC0), NASA/JPL-Caltech/ASU/MSSS (regional rover panorama PIA24921). HiRISE usage: https://uahirise.org/media/usage.php . Regional panorama source: https://science.nasa.gov/resource/detailed-panorama-of-mars-jezero-crater-delta/ . The image illustrates Jezero context; it is not from these hypothetical stops.

The script also packages the regional panorama from contextImage in the source manifest, downloading it only if absent. WebP encoder differences may alter hashes across library versions.

Hashed JSON assets use UTF-8 and LF line endings, enforced by `.gitattributes` and `write_json` in the preparation script. Always hash the final serialized bytes. This prevents Windows CRLF conversion from invalidating the mission hash on Linux/Vercel.

The scanner also packages `relief.f32`, a 513 × 513 Float32 grid sampled directly from the same DTM crop at 4 m. The 8 m grid defines route calculations and provides a rendering fallback. The scalar sidecars `slope.u8` and `thermal.u8` share that 8 m grid's registration. Slope is encoded in quarter degrees with 255 reserved for missing coverage. Thermal stores nearest-reprojected DN with 0 reserved for missing coverage. Its underlying source spacing is about 100 m.


## Crew, hazards and science atlas

The crew simulation uses the existing editable route in forward order for Alpha and reverse order for Bravo. Both teams have a leader and a buddy with a six-second departure offset. Walking uses horizontal route distance and the configured speed, with the existing dwell at included stops. Playback is deterministic and session-only. Crew names, roles, habitat geometry and enlarged suited-human map symbols are illustrative. Coordinate anchors remain in the terrain frame, independently of symbol enlargement and readability offsets.

Terrain-derived hazard zones are connected 8 m cells whose center slope exceeds the existing illustrative 15° threshold. All connected zones remain in the route conflict model. Only six slope regions receive map labels. The scenario source record data/jezero/scenario-sources.json describes the reviewed depression-edge, loose-material and scarp annotations, plus the disabled-by-default dust event. The depression measurement compares center elevation at (296 E, 1392 N) with four elevations 64 m away, yielding about 7.16 m of local relief. Polygon annotations support educational route review. The communications note describes possible obstruction without calculating a radio link budget. Route conflicts use segment/zone intersections and include boundary contacts.

Run python scripts/prepare_science_atlas.py to package the four additional evidence figures from data/jezero/science-atlas-sources.json. The script keeps original downloads under .data-staging/science-atlas, checks their recorded SHA-256, preserves the full figure without cropping, limits output dimensions to 1600 px, and writes attributed WebP assets plus LF JSON and runtime checksums. The four images total 950,346 bytes. PIA23380 supplies regional CRISM/CTX mineral context. PIA25025 supplies the published RIMFAX Artuby traverse/radargram. PIA17600 supplies Curiosity RAD measurements at Gale crater during August 2012–June 2013. PIA25041 supplies the PIXL Dourbes target composite. Source records retain product identifiers, scope, axes/units, credits, image transformations and publication/observation context. Their published location context stays distinct from the local patch. Individual evidence failures retain source information.

The terrain preparation manifest now includes nested atlas assets recursively. Verify all bundled assets with python scripts/prepare_mars_data.py --verify-only.
